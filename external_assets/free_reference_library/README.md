# Crônicas de Valedouro — Biblioteca Gratuita de Referência 2D

Esta pasta reúne assets gratuitos selecionados para servir de matéria-prima e referência de modelagem do mundo.

## Regra principal
Estes arquivos NÃO substituem a direção visual oficial de Crônicas de Valedouro.
Claude/Opus deve adaptar escala, perspectiva, paleta, luz, sombra, volume, densidade e acabamento ao padrão visual já aprovado antes de promover qualquer asset ao catálogo oficial.

## Categorias
- nature/: árvores e vegetação
- characters/: bases para heróis e personagens
- monsters/: peças e referências para criaturas
- equipment/: armas, armaduras, escudos, itens e ícones
- buildings/: casas, vilas, castelos, torres, telhados e estruturas
- dungeons/: referências de masmorra
- karsiori/: vegetação aprovada como referência visual específica

## Uso no projeto
1. Não integrar automaticamente ao renderer.
2. Criar equivalentes/refinamentos coerentes com o estilo oficial.
3. Registrar IDs persistentes no catálogo.
4. Respeitar transparência, escala, colisão e perspectiva.
5. Validar visualmente no Godot 4.7.2 antes de promover para APPROVED.
6. Preservar desempenho mobile.
